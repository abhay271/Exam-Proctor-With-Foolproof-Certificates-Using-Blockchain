# 📚 Text-to-Speech (TTS) Feature - Documentation Index

## Welcome to ExamFlow TTS Feature Documentation!

This feature adds **Azure OpenAI-powered Text-to-Speech** to exam questions, making ExamFlow more accessible and supporting **UN SDG 4: Quality Education**.

## 💡 Tips & Best Practices

### For Optimal Performance
- ✅ Let audio files cache (don't delete audio_cache/)
- ✅ Use test_tts.php to verify before production
- ✅ Monitor Azure API usage for cost optimization

### For Best User Experience
- ✅ Inform students about TTS feature
- ✅ Encourage use for accessibility needs
- ✅ Collect feedback for improvements

### For Maintenance
- ✅ Periodically check API connectivity
- ✅ Monitor cache directory size
- ✅ Review error logs occasionally
